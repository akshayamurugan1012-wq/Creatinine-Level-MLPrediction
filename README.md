
# Creatinine Level Prediction

## Project Overview
This project predicts creatinine levels using Machine Learning.

## Features
- Predicts creatinine levels
- Displays risk alert when creatinine > 1.5 mg/dL
- Model evaluation using confusion matrix

## Files
- creatinine_model.pkl : Trained ML model
- train_model.ipynb : Training notebook
- dataset.csv : Dataset
- README.md : Project documentation

## Requirements
- Python 3.x
- Pandas
- NumPy
- Scikit-learn

## How to Run
1. Install requirements
2. Load the model
3. Enter patient data
4. Get prediction
